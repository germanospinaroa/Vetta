# Conversion Landing

Use the approved copy and product context as a hard boundary. Build a mobile-first hero, a compact value path, visible price, one clear CTA and a simple checkout handoff. Use real assets only from `assets/ASSET_REGISTRY.md`; if a key asset or checkout URL is missing, expose the pending state instead of fabricating it.

Prioritize hierarchy, scanability, touch targets, performance and accessibility. Do not add new benefits, modules, testimonials, urgency, scarcity, guarantees or economic promises. Do not add distracting navigation or unrequested functionality.
