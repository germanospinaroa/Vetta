# Launch checklist

- [ ] Production/preview URL confirmed
- [ ] Variables verified without exposing values
- [ ] Build and critical flow pass on target environment
- [ ] Migrations and rollback understood
- [ ] Security review complete
- [ ] Metadata, favicon, robots, sitemap, canonical complete
- [ ] Legal pages present where applicable
- [ ] Analytics explicitly authorized
- [ ] Monitoring and rollback owner identified
- [ ] Publish authorization recorded
