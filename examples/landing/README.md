# Minimal landing example

Copy `templates/PRODUCT-BRIEF.template.md` and `templates/DESIGN.template.md` into a new landing project. Complete the objective, audience, primary CTA, concrete tokens, one responsive page, and all relevant states. For a static landing, skip architecture artifacts that do not add a decision; retain `DESIGN.md`, page acceptance, QA, and launch checklists.
